# Active Vida Leve

Landing page responsiva do projeto Active Vida Leve.

## Estrutura
- `index.html` — estrutura da página inicial
- `assets/css/global.css` — tokens visuais e estilos globais
- `assets/css/index.css` — estilos específicos da página inicial
- `js/index.js` — inicialização dos recursos da página
- `modules/carousel.js` — comportamento do carrossel principal
- `assets/images/` — imagens efetivamente utilizadas pela página

## Breakpoints
- até `1080px` — notebook / desktop menor
- até `900px` — tablet
- até `640px` — mobile
- até `380px` — mobile compacto

## Cores principais atuais
- verde escuro: `#0E6B3A`
- verde vibrante: `#22C55E`
- laranja: `#F97316`
- amarelo: `#FFB703`
- texto escuro: `#263E32`
- creme: `#F9F7ED`

## Convenção de manutenção
Alterações devem ser feitas diretamente nas regras-fonte correspondentes. Evitar patches acumulados no fim dos arquivos, duplicações e regras obsoletas.
