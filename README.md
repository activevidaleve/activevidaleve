# Active Vida Leve — Redesign

Versão visual totalmente reformulada do portal Active Vida Leve.

## O que mudou

- **Nova identidade visual**: paleta suave de verdes + cream, tipografia Fraunces + DM Sans
- **Hero redesenhado**: layout em duas colunas com cards flutuantes (sem carrossel automático)
- **Seções reorganizadas** com mais respiro e hierarquia clara
- **Cards de conteúdo** com overlay em imagem
- **Feedbacks** em carrossel horizontal com fundo escuro
- **FAQ** em accordion limpo
- **CTA** com destaque em bloco
- **Mesmos conceitos e conteúdos**: alimentação, movimento, receitas, como funciona, experiências, FAQ

## Estrutura

```
index.html
assets/css/global.css
assets/css/index.css
assets/images/   (mesmos assets originais)
js/index.js
modules/
  feedback-carousel.js
  mobile-menu.js
```

## Como usar

Abra `index.html` em um servidor local ou publique no GitHub Pages.
